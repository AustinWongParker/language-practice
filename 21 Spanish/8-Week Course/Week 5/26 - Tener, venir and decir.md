# Lesson 26 · Tener, venir and decir
**Week 5 · Irregular verbs and people** · about 30 min · [[Spanish 8-Week Course|Course overview]] · ← [[25 - Yo-go verbs - hacer, poner, salir, traer|Lesson 25]] · [[27 - Saber vs conocer|Lesson 27]] →

> [!tip] Goal
> Use tener, venir and decir, plus everyday tener expressions.

## 1 · Learn (10 min)
Three common verbs with a **-go** yo form *and* a stem change:

| | tener (have) | venir (come) | decir (say, tell) |
|---|---|---|---|
| yo | **tengo** | **vengo** | **digo** |
| tú | tienes | vienes | dices |
| él / ella / usted | tiene | viene | dice |
| nosotros | tenemos | venimos | decimos |
| ellos / ustedes | tienen | vienen | dicen |

**Tener** expressions, where English uses "to be": **tener hambre** (hungry) · **tener sed** (thirsty) · **tener sueño** (sleepy) · **tener frío / calor** (cold / hot) · **tener prisa** (in a hurry) · **tener razón** (right)

**New words**

| Spanish | English |
|---|---|
| tener hambre | to be hungry |
| tener sed | to be thirsty |
| tener sueño | to be sleepy |
| tener prisa | to be in a hurry |
| tener razón | to be right |
| venir | to come |
| decir | to say, tell |
| la verdad | truth |

**Listen for:** tengo or tiene plus a feeling (hambre, frío, sueño).

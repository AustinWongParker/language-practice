# Lesson 3 · Estar for feelings and location
**Week 1 · Foundations** · about 30 min · [[Spanish 8-Week Course|Course overview]] · ← [[02 - Ser for who you are and where you're from|Lesson 2]] · [[04 - Want, can and have to|Lesson 4]] →

> [!tip] Goal
> Say how you feel and where things are.

## 1 · Learn (10 min)
**Estar** (also "to be") is for how something *is* right now (feelings, states) and *where* it is.

| | estar |
|---|---|
| yo | **estoy** |
| tú | **estás** |
| él / ella / usted | **está** |
| nosotros | **estamos** |
| vosotros | **estáis** |
| ellos / ellas / ustedes | **están** |

- Feelings: **Estoy contento** (happy) · **¿Estás ocupada?** (busy?)
- Location: **¿Dónde está el baño?** · **Estoy en casa.**
- Quick rule: **ser = what it is · estar = how or where it is.** Compare **Es aburrido** (he's boring) with **Está aburrido** (he's bored).
- Make any sentence negative by putting **no** before the verb: **No estoy cansado.**

**New words**

| Spanish | English |
|---|---|
| estar | to be (state, place) |
| contento / contenta | happy |
| triste | sad |
| ocupado / ocupada | busy |
| enfermo / enferma | sick |
| en casa | at home |
| aquí | here |
| ¿dónde? | where? |

**Listen for:** está and estoy, and whether it's a feeling or a place.

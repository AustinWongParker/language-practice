# Lesson 40 · Preterite irregulars - estar, poder, decir, ver, dar
**Week 7 · The past (preterite)** · about 30 min · [[Spanish 8-Week Course|Course overview]] · ← [[39 - Preterite irregulars - ir, ser, hacer, tener|Lesson 39]] · [[41 - Past time words|Lesson 41]] →

> [!tip] Goal
> Use five more irregular past-tense verbs.

## 1 · Learn (10 min)
| | estar | poder | decir |
|---|---|---|---|
| yo | **estuve** | **pude** | **dije** |
| tú | **estuviste** | **pudiste** | **dijiste** |
| él / ella / usted | **estuvo** | **pudo** | **dijo** |
| nosotros | **estuvimos** | **pudimos** | **dijimos** |
| ellos / ustedes | **estuvieron** | **pudieron** | **dijeron** |

| | ver | dar |
|---|---|---|
| yo | **vi** | **di** |
| tú | **viste** | **diste** |
| él / ella / usted | **vio** | **dio** |
| nosotros | **vimos** | **dimos** |
| ellos / ustedes | **vieron** | **dieron** |

The first group follows one pattern: an irregular stem plus **-e, -iste, -o, -imos, -ieron** (but **dijeron**, not *dijieron*).

**New words**

| Spanish | English |
|---|---|
| estuve | I was (somewhere) |
| pude | I managed to, could |
| dije | I said |
| vi | I saw |
| di | I gave |
| todo el día | all day |
| no pude | I couldn't |

## 2 · Practice (10 min)

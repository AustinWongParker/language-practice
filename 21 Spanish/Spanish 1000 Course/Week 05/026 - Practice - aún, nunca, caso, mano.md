## 3 · Textbook (5 min): Where adjectives go
Read the rule out loud, do the exercise, then check the answers. All units: [[Textbook Units]].

Most adjectives go **after** the noun: **un coche rojo**, **una idea interesante**, **la comida mexicana**.

Some go **before**:
- Numbers and quantities: **dos casas**, **muchos amigos**, **poco tiempo**, **otra vez**
- **bueno** and **malo** often: **una buena idea**, **un mal día**

**Short forms** before a masculine singular noun: **bueno → buen**, **malo → mal**, **primero → primer**, **tercero → tercer**, **alguno → algún**, **ninguno → ningún**. **Grande → gran** before any singular noun: **un gran día**, **una gran idea**.

**Some change meaning with position:**
| Before | After |
|---|---|
| un **gran** hombre = a great man | un hombre **grande** = a big man |
| un **viejo** amigo = a longtime friend | un amigo **viejo** = an elderly friend |
| la **pobre** mujer = the unfortunate woman | la mujer **pobre** = the poor (no money) woman |
| el **mismo** día = the same day | |
| mi **única** hija = my only daughter | una hija **única** = a unique daughter |
| un **nuevo** coche = a different (new to me) car | un coche **nuevo** = a brand-new car |

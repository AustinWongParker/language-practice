## 3 · Textbook (5 min): Where object pronouns go
Read the rule out loud, do the exercise, then check the answers. All units: [[Textbook Units]].

Object pronouns (**me, te, lo, la, le, nos, los, las, les, se**) have three possible spots:

1. **Before a conjugated verb:** **Lo veo.** · **No te entiendo.** · **Me lo dio.**
2. **Attached to an infinitive or gerund** (or before the helper verb; both are correct):
   - **Voy a llamarte.** = **Te voy a llamar.**
   - **Estoy leyéndolo.** = **Lo estoy leyendo.**
3. **Attached to an affirmative command** (but before a negative one):
   - **¡Dímelo!** · **¡Cómpralo!** vs **¡No me lo digas!** · **¡No lo compres!**

- Attaching can move the stress, so add an accent to keep it in place: **leyendo → leyéndolo**, **di → dímelo**, **compra → cómpralo**.
- Order when there are two: **indirect before direct** (me lo, te la, se los).

**Exercise:** Rewrite with the pronoun in the other correct position.

2. Te quiero ver. → 
3. Estoy haciéndolo. → 
4. Me lo tienes que decir. → 
5. Make it positive: ¡No lo abras! →

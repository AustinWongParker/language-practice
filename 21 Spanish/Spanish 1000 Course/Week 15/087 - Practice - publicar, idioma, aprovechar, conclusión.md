## 3 · Textbook (5 min): Pronunciation: stress changes meaning
Read the rule out loud, do the exercise, then check the answers. All units: [[Textbook Units]].

Where the stress falls can change a word completely. The written accent shows you.

| | | |
|---|---|---|
| **papa** = potato | **papá** = dad | |
| **esta** = this | **está** = is | |
| **hablo** = I speak | **habló** = he spoke | |
| **termino** = I finish | **terminó** = he finished | **término** = term |
| **practico** = I practice | **practicó** = he practiced | **práctico** = practical |
| **ingles** = groins | **inglés** = English | |

**Intonation:**
- Statements fall at the end: **Tienes tiempo.** ↘
- Yes/no questions rise: **¿Tienes tiempo?** ↗
- Questions with a question word usually fall: **¿Dónde vives?** ↘

**Exercise:** Read each one aloud with the right stress. Then say what it means.

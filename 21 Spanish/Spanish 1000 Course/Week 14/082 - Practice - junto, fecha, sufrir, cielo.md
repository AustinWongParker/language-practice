## 3 · Textbook (5 min): Negation and double negatives
Read the rule out loud, do the exercise, then check the answers. All units: [[Textbook Units]].

- **No** goes right before the verb (and before any object pronouns): **No lo sé.** · **No me gusta.**
- Spanish **requires** double negatives: if a negative word comes after the verb, you still need **no** before it:
  - **No veo nada.** = I don't see anything. (lit. I don't see nothing)
  - **No hay nadie.** = There's nobody.
  - **No voy nunca.** = I never go.
- If the negative word comes first, drop **no**: **Nunca voy.** · **Nadie vino.** · **Nada es fácil.**

| Positive | Negative |
|---|---|
| algo (something) | nada (nothing) |
| alguien (someone) | nadie (nobody) |
| alguno/a (some) | ninguno/a (none) |
| siempre (always) | nunca, jamás (never) |
| también (also) | tampoco (neither) |
| o... o (either... or) | ni... ni (neither... nor) |

- **Ninguno** is almost always singular: **No tengo ningún problema.**

**Exercise:** Make the sentence negative.

1. Veo algo. → 
2. Alguien llama. → 
3. Siempre como aquí. → 
4. Tengo algunos amigos aquí. → 
5. Yo también. → 
6. Quiero té o café. →

> 1. No veo nada.
> 2. Nadie llama. / No llama nadie.
> 3. Nunca como aquí. / No como aquí nunca.
> 4. No tengo ningún amigo aquí.
> 5. Yo tampoco.
> 6. No quiero ni té ni café.

## 3 · Textbook (5 min): Time expressions with hace, desde and llevar
Read the rule out loud, do the exercise, then check the answers. All units: [[Textbook Units]].

| To say | Use | Example |
|---|---|---|
| ... **ago** | **hace** + time (+ preterite) | Llegué **hace dos años**. = I arrived two years ago. |
| **have been** doing for ... | **hace** + time + **que** + present | **Hace tres meses que** estudio español. |
| same, other order | present + **desde hace** + time | Estudio español **desde hace** tres meses. |
| same, very common | **llevar** + time + gerund | **Llevo** tres meses estudiando español. |
| **since** a point in time | **desde** | Vivo aquí **desde** 2020. |
| How long have you...? | **¿Cuánto tiempo hace que...?** / **¿Cuánto tiempo llevas...?** | ¿Cuánto tiempo llevas aquí? |

- English uses "have been" but Spanish uses the **present**, because the action is still going on: ~~He estudiado~~ → **Estudio español desde hace tres meses.**

**Exercise:** Say it in Spanish.

1. I moved here three years ago. → 
2. I've been studying Spanish for two months. → 
3. I've lived here since 2020. → 
4. How long have you been working here? → 
5. She called an hour ago. → 
6. We've known each other for ten years. → 

> [!check]- Answers (check after you try)
> 1. Me mudé aquí hace tres años.
> 2. Hace dos meses que estudio español. / Llevo dos meses estudiando español.
> 3. Vivo aquí desde 2020.
> 4. ¿Cuánto tiempo hace que trabajas aquí?
> 5. Llamó hace una hora.
> 6. Nos conocemos desde hace diez años.
